Лабораторна робота №4 — адаптивний дизайн веб-сторінок HTML/CSS

Вміст: index.html, biography.html, nowadays.html, friends.html, gallery.html, style.css, image-local.png та images/image-folder.png.

Усі п’ять HTML-сторінок створено на основі файлів лабораторної №2. Оригінальні стилі перенесено в один зовнішній файл style.css, після чого додано CSS Grid і медіазапити для мобільних пристроїв, планшетів і комп’ютерів.

Відкрити: index.html у браузері (після повного розпакування архіву).
Папку lab4 повністю завантажити до репозиторію GitHub поряд із lab1, lab2, lab3.
Очікувана адреса після публікації: https://denysartomenko24-ux.github.io/lab1web/lab4/
